# 개념 한 장

정보처리기사 실기 개인 학습용 카드 앱. 첨부된 세 PDF를 참고해 재구성한 개념 문제 172개를 포함합니다. 원본 PDF는 포함하지 않습니다.

## 사용

- 9개 파트에서 선택 → 고정된 37개 묶음(최대 5개)으로 개념 읽기 → 해당 묶음 퀴즈 → 다음 묶음.
- 파트의 모든 묶음 퀴즈를 완료하면 파트 랜덤 복습이 열립니다. 해당 파트에서 최대 10개의 개념을 중복 없이 뽑고, 완료 후 다른 랜덤 회차를 시작할 수 있습니다. 진행 중 회차는 답안과 위치를 이어갑니다.
- 풀이 기록에서 파트·학습 방식·회차·결과를 조합하여 조회합니다. 전체 랜덤의 문항도 개별 개념이 속한 파트로 필터링합니다.
- 172개 개념마다 한글 제목과 영어 표기, 쉬운 설명, 이해용 예시(기출 아님), 키워드, 시험 답안, 출처·별표 근거를 제공합니다. 영어 표기는 학습 화면과 정답을 확인한 퀴즈·풀이 기록에 표시합니다. 읽음과 퀴즈 완료는 별개입니다.
- 각 묶음의 개념을 읽은 뒤 해당 묶음 퀴즈에서 관련 용어 단답형, 여러 명칭을 쓰는 빈칸형, SQL 코드 빈칸형과 영문 명령어 쓰기형을 풉니다. 퀴즈 문장은 `무엇인가?`·`쓰시오.` 같은 시험 문체를 사용하며, 쉬운 말투는 개념 설명에만 사용합니다. 용어 문제는 가능한 경우 `하드웨어 노드와 ... 다이어그램은 무엇인가?`처럼 개념을 묻는 문장으로 제시합니다. 묶음에 포함되지 않은 개념을 빈칸형에 끼워 넣지 않습니다. 설명형 문제가 필요한 개념은 기존 형식을 유지합니다. 실제 기출문을 그대로 옮긴 문항은 아닙니다.
- 진행 중인 묶음 퀴즈나 전체 랜덤 퀴즈를 다시 누르면 기존 회차의 답안과 위치를 그대로 이어갑니다. 풀이가 없는 이전 회차는 기록 목록에서 숨기고, 답안을 쓴 회차는 보존합니다.
- 전체 랜덤 30문제에도 같은 유형을 섞되 한 회차에 같은 개념이 두 번 나오지 않도록 합니다. 정답 확인 뒤 스스로 정답/부분정답/오답을 평가합니다. SQL 영문 명령어는 대소문자를 구분하지 않고 철자와 띄어쓰기를 자동 확인합니다.
- 제공된 시험 대비 자료 이미지의 형식을 참고해 21개 학습 개념에 22개 재구성 문항을 연결했습니다. 설명형 단답, 공통 빈칸, 번호별 빈칸, 영어 보기에서 찾아 쓰기, 영문 약어 쓰기, UML 그림 판별을 기존 묶음·랜덤 퀴즈에서 제공합니다. 그림은 직접 작성했으며 원문 이미지를 배포하지 않습니다. 진행 중인 회차의 문항·답안은 유지되고 새 회차부터 새 유형을 사용합니다.
- 새로 작성한 빈칸형과 SQL 예제의 답안, 보기와 그림 구분 정보는 풀이 기록과 JSON 백업에 남습니다.
- 풀이 기록에서 회차별 답안, 모범답안, 출처와 별표 근거를 확인합니다.
- 기록은 같은 origin의 같은 브라우저 localStorage에 저장됩니다. 데이터 삭제 또는 주소·기기 변경 전 JSON 백업을 내려받으세요.
- 백업 복원은 전체 검증 후 회차 ID로 병합하며, 같은 회차는 최근 updatedAt 기록을 유지합니다.

## 실행 및 구성

`dist`를 정적 웹 서버로 서비스합니다. PWA 배포 전에는 `npm run build`로 서비스 워커를 생성합니다. 외부 API나 추가 패키지는 필요하지 않습니다.

- `bank.js`: 고정 ID와 버전, 문제·모범답안·키워드·해설·출처·별표 근거.
- `learn-data.js`: 172개 학습 설명·예시·영어 표기와 고정된 학습 순서, 37개 묶음의 ID·버전·문제 목록. 묶음 구성을 바꿀 때는 버전을 올립니다.
- `core.js`: 무작위 추출, 상태 검증, 회차 생성·평가, 백업 병합.
- `app.js`: 화면, 묶음·랜덤 퀴즈의 출제 형식, localStorage 자동 저장, 내보내기·복원.
- `styles.css`, `ui.css`: 모바일/데스크톱 레이아웃과 rem 기반 글자 크기.

저장 키: `concept-cards:v1`(유지). 스키마: `concept-cards/v3`. v1/v2 백업은 계속 가져올 수 있습니다. v3에는 `part-random` 회차와 파트명이 추가되므로 복원할 기기의 앱도 최신 버전을 사용합니다.
v1 기록은 검증 후 메모리에서 v2로 변환하며, 최초 저장 성공 전 원본은 변경하지 않습니다. v1 백업도 가져올 수 있습니다. v2 백업은 이전 버전 앱에서 읽을 수 없으므로 사이트를 새로고침한 후 복원합니다.
회차는 random(30개) 또는 bundle(1~5개)이며 문제·답안 스냅샷과 묶음 메타데이터를 저장합니다. 읽음은 개념 ID별 타임스탬프, 마지막 위치는 묶음·개념 ID와 타임스탬프를 저장합니다. 복원은 읽음 기록 합집합과 더 최근의 마지막 위치를 유지합니다.
별표 중 핵심은 학습용 분류, 기출·빈출은 첨부 자료에서 확인된 표시와 회차를 근거로 합니다.
필요한 브라우저 API를 지원하지 않으면 WebMCP 등록은 생략합니다.

## 검증

1,000회 랜덤 추출의 회차별 30개/중복 없음, 문제 스냅샷 독립성, 백업 왕복·병합·오류 거부를 검증했습니다.
Chrome 자동화로 30문제 완주, 새로고침 후 답안/위치 복구, 기록 필터, JSON 다운로드·복원, 잘못된 파일의 기존 기록 보존, 모바일/200% 글자 확대, 저장 공간 오류·손상 기록 보존을 확인했습니다.
WebMCP 도구는 모의 등록 환경에서 정상/잘못된 입력을 확인했으며 실제 지원 브라우저 연동 검증은 수행하지 않았습니다.
172개 개념의 영어 표기 누락·중복 키를 확인하고, 정답 확인 전에는 퀴즈에서 영어 표기가 보이지 않는지 확인했습니다. 기본·추가 문제 293개의 구어체 문장을 점검하고, 진행 중인 예전 회차의 답안을 유지하면서 문항 문구를 갱신하는 동작을 확인했습니다. 묶음 퀴즈의 단답형·여러 빈칸형·SQL 코드 빈칸형·영문 명령어 쓰기형과 전체 랜덤 문제 혼합을 확인했습니다. 진행 중 회차 재진입 시 답안·문제 위치가 보존되고 중복 회차가 생성되지 않는지도 확인했습니다. 문제별 개념 ID, 출처, JSON 기록 스키마를 유지합니다.
파트별 학습 추가 검증: 172개 고유 매핑·출처 페이지, 1~5개 회차, v1/v2 마이그레이션·병합, 읽던 위치와 퀴즈 답안 복구, 1/3/4/5/30문제 완주, 모바일 화면, 손상 JSON 비파괴 거부.

## 휴대폰 앱으로 설치 (PWA)

Vercel의 공개 HTTPS 주소를 Android Chrome에서 연 뒤 화면의 **앱 설치** 버튼이나 Chrome 메뉴의 **앱 설치/홈 화면에 추가**를 선택합니다. 처음 방문할 때 모든 학습 파일을 받아 두면 이후에는 인터넷 없이 학습할 수 있습니다. iPhone은 Safari 공유 메뉴에서 **홈 화면에 추가**를 선택합니다.

PC의 localhost, 다른 웹 주소, 설치한 PWA는 저장 공간이 다를 수 있습니다. 기록을 옮기려면 기존 앱의 **백업 · 복원**에서 JSON 파일을 내려받아 새 주소 또는 휴대폰에서 불러오세요. 자동 동기화는 제공하지 않습니다.

PWA 배포 시 `npm run build`로 `dist/sw.js`를 생성합니다. 서비스 워커는 같은 버전의 정적 파일을 모두 캐시한 뒤 활성화하며, 새 버전은 다음 실행에서 적용됩니다. `student` 브랜치에서 작업한 뒤 `main`에 병합하면 Vercel 프로덕션이 배포됩니다. 출력 디렉터리는 `dist`입니다.

이번 문항 유형 변경은 22개 문항의 화면 HTML 생성·정답 공개 전후·이어 풀기, 37개 묶음의 학습 범위 일치, 랜덤 100회 추출 및 백업 검증을 모의 실행 환경에서 확인했습니다. 실제 브라우저의 시각적 검증은 로컬 실행 도구 오류로 수행하지 못했습니다.

영문 답안 형식 보완: 설명형 용어, 영문 전체 이름, 영문 약어, 전체 이름/약어 중 선택, 보기 그대로 작성의 답안 안내와 자기평가 조건을 문항별로 표시합니다. 네트워크·IT의 12개 재구성 문항을 더해 형식 예시 문항은 34개입니다. 기존 학습 개념에만 연결하며, 34개 문항의 안내·정답 공개·JSON 왕복 및 37개 묶음의 학습 범위를 모의 실행으로 검증했습니다.
